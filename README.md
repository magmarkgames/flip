# FLIP v0.9

- Hauptmünze per Wischgeste werfen; Geschwindigkeit und Strecke beeinflussen Höhe und Dauer, nicht das Ergebnis. Bonusmünzen weiterhin antippen. Tastatur: Enter/Leertaste.
- Streaks: 3 orange (Duplication ×2), 5 rot (×3), 7 gold (garantierter Bonus), 10 lila (garantierter Goldbonus), 15 türkis (Goldbonus und ×5 Hauptgewinn). Spawn-Meilensteine einmal pro Erreichen, nicht bei geschützter Serie.
- Critical Flip: 200 Coins Startpreis, Freischaltung nach 500 insgesamt verdienten Coins, 1–5 %, ×10 auf erfolgreiche Würfe.
- Vorhandener Spielstand bleibt über den bisherigen localStorage-Schlüssel erhalten.

Installation: index.html im GitHub-Repository ersetzen. Keine externen Abhängigkeiten.
