# FLIP v0.12

Ersetze die index.html im bestehenden GitHub-Repository. Der lokale Spielstand bleibt kompatibel.

- 3 Totenköpfe: 1 Silbermünze. 4: 2 weitere Silbermünzen.
- Ab 5: einmaliger Multiplikator entsprechend der Länge der negativen Serie auf den nächsten erfolgreichen Hauptwurf, inklusive Critical Flip.
- Neue Metallplaketten für Streaks, warme Farben für positive Serien, kalte Farben für negative Serien.
- Negative Serien werden anhand der endgültigen Hauptmünzen-Ergebnisse gezählt; bestehende Schutz- und Wiederholungsmechaniken bleiben erhalten.
